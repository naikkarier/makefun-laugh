# The One-Line Laugh

One funny line, 134 characters, a single sentence on any subject. Entry for the make.fun bounty "The One-Line Laugh" ($5).

`main.py` writes the line to `/output/entry.txt` and validates it is 1 to 200 characters on a single line.
